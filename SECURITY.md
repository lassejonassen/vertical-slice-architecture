# Security Policy

## Supported Versions

This project follows [Semantic Versioning](https://semver.org/) (`MAJOR.MINOR.PATCH`).
No tagged releases exist yet — once versioning starts, only the latest major
version will receive security fixes.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report it privately using [GitHub Security Advisories](https://github.com/lassejonassen/vertical-slice-architecture/security/advisories/new)
("Report a vulnerability" under the repo's Security tab). This keeps the
report private until a fix is available.

Include as much detail as you can:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a proof-of-concept
- Affected version/commit

This is a single-maintainer project, so response times are best-effort. You
can expect an initial acknowledgement within a few days. If the report is
confirmed, a fix will be prioritized and a new version released; you'll be
credited in the advisory unless you'd prefer otherwise. If declined, you'll
get an explanation of why.
